# Розрахунок площі функції методом Монте-Карло

Відповідний алгоритм описаний у функції `monte_carlo_method`. Точність алгоритму була встановлена на рівні 150000 точок.
Для перевірки розрахунку використовується метод `integrate.quad` з пакету scipy. Так як метод Монте-Карло є рандомізованим
алгоритмом, який використовує випадковість та ймовірність в розрахунку площі було використано 10 ітерацій виклику функції
`monte_carlo_method`. Отримані значення були записані та на кожній ітерації була розрахована дельта з результатом методу
`integrate.quad`. В кінці розраховано середнє відхилення для методу Монте-Карло.

Для обчислення площі була використана функція f(x)=x² .
